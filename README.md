# Personal Portfolio Website

A responsive portfolio starter built with plain HTML, CSS, and JavaScript.

## Folder structure

- `index.html` — homepage and featured projects
- `projects.html` — project descriptions, technologies, and links
- `blog.html` — article listing
- `blog/` — individual article pages
- `resume.html` — web CV and PDF download link
- `contact.html` — contact details and email-preparation form
- `css/style.css` — styling, responsive layout, and dark theme
- `js/main.js` — mobile navigation, theme toggle, year, and contact form
- `assets/` — add images and your `resume.pdf` here

## Run locally

Open `index.html` in a browser, or use VS Code with the Live Server extension.

## Personalise before publishing

1. Replace every `Your Name` with your preferred display name.
2. Replace `your.email@example.com` and the sample GitHub/LinkedIn URLs with your real details.
3. Update project descriptions and replace placeholder demo/source links.
4. Add your CV PDF at `assets/resume.pdf`.
5. Add your own images to `assets/` and reference them from the HTML.
6. Test every page and link on desktop and mobile.

## Free hosting

You can publish this static website with GitHub Pages, Netlify, or Cloudflare Pages. No backend is required for the current version. The contact form opens the visitor's email app; a server-backed form would require a form service or backend.
