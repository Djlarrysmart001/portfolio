Getting Started with Web Development

A simple introduction to the three core technologies behind many websites.

HTML: the structure

HTML defines the content and structure of a web page: headings, paragraphs, links, images, forms, and other elements.

CSS: the presentation

CSS controls how a page looks, including its colours, spacing, layout, typography, and how it adapts to different screen sizes.

JavaScript: the behaviour

JavaScript adds interaction, such as opening a mobile menu, validating a form, or switching between light and dark themes.

Build by doing

Start with a small page, test it in your browser, and improve it in manageable steps. Keep your files organised and use Git to track your changes.
